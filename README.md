# КЕГЭ | Информатика

[Открыть сайт](https://smrdmitriy.github.io/KEGEinf/)

Светлая образовательная платформа: React, TypeScript, Vite, Tailwind CSS, Supabase. 27 модулей, кабинет ученика с прогрессом и историей попыток, кабинет преподавателя с группами, редактором задач и назначениями. Для №5 доступны интерактивные слайды и тренировочные задачи.

## Исходники и запуск

Первичная публикация выполнена через браузер. Все исходники находятся в `kege-source.tar.gz`; workflow с доступом `contents: read` распаковывает их во время сборки. Архив не содержит зависимостей, секретов или пользовательских данных.

```sh
tar -xzf kege-source.tar.gz
cd kege-platform
npm ci
npm run dev
```

Подробная документация: `kege-platform/README.md` после распаковки. Для обычной разработки можно закоммитить распакованную папку `kege-platform`: если её package.json присутствует, workflow использует исходники напрямую.

## Проверки

```sh
npm run test:security
npm run build
```

Тест базы проверяет RLS, роли, закрытые ответы, серверную проверку попыток и изоляцию учеников и преподавателей в локальном PostgreSQL (PGlite).

## Supabase

Без настроек сайт работает в явно обозначенном локальном деморежиме: данные хранятся только в браузере. Для настоящих учётных записей примените `kege-platform/supabase/migrations/001_platform.sql` в новом Supabase-проекте, добавьте GitHub Actions Variables `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY` и повторно запустите workflow. Используйте только публичный anon/publishable key, никогда не service_role. Роль преподавателя назначает администратор базы.

Pyodide, вложения и полная теория остальных номеров пока не реализованы.
